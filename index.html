Flow

A tool for product builders and vibe coders, to stay in the flow.

Welcome to Flow

A board where cards become live agent sessions. Three steps to your first one:

  1. Add a project, any local repo
  2. Write a card for something you want built
  3. Drag it into Doing and talk to the session that opens

Default terminal command The CLI every session launches — cards, the board terminal, the docs terminal. A command name like claude or codex, or a full path to a script. A card's session launches it on open so the agent sits ready; prompts are only ever pasted for you to send. Empty means claude.

Shaping

Model command How Shape starts the model — a CLI and its flags, e.g. claude -p. The model, prompt and streaming flags are appended. Empty means the default.
Model The claude model shaping runs on — haiku is the default and keeps shapes near-instant; sonnet writes richer plans. Wins over any --model in the command above. Emptying the field restores the default.
Shaping prompt The instructions Shape sends. The card's title, its context and a glance at the repository are appended after this, whatever it says. Restoring the default is emptying the field and saving.
